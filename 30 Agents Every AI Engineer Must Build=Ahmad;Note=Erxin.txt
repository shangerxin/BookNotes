Model Context Protocol (MCP): standardizes agent interactions with tools, APIs, and data sources. Rather than hardcoding tool-specific logic into each agent, MCP defines a universal interface layer that enables agents to discover, evaluate, and invoke external services dynamically. 

Agent-to-Agent (A2A) Protocols: define message-passing interfaces between collaborating agents in a decentralized system.
