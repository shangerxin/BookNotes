In general, you need roughly 1.2 GB per billion parameters for the base model at 8-bit precision.The actual file and memory sizes for 100B and 300B parameter models vary based on the format:100B Parameter Models(e.g., Solar Open 100B, Claude 3 Sonnet)Full Precision (FP16): ~200 GB file size, requires ~220+ GB VRAM.8-Bit Quantization (Q8): ~105 GB file size, requires ~120 GB VRAM.4-Bit Quantization (Q4): ~55 GB file size, requires ~60 GB VRAM.300B Parameter Models(e.g., ERNIE 4.5)Full Precision (FP16): ~600+ GB file size, requires ~650+ GB VRAM.8-Bit Quantization (Q8): ~310 GB file size, requires ~350 GB VRAM.4-Bit Quantization (Q4): ~160 GB file size, requires ~180+ GB VRAM.
